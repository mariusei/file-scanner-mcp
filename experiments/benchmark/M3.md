## Preregistered outcomes

- **P1 (B ≥ +15 pp on class C): nominally met (+16.7 pp) but NOT credited.**
  The entire margin is the two arm-A operational failures; in every episode
  where the arm-A agent got its tools working it found the planted fact by
  search. The preregistration did not anticipate this failure mode; crediting
  P1 on it would be dishonest.
- **P2 (cost guard on class N): coverage holds (36/36 both), token guard
  BREACHED (+29.8% > +10%).** Mechanistically plausible, not just variance:
  on neutral tasks arm-B agents explore more and tails fire on unrelated
  files scanned en route. n is small; the direction is consistent with the
  noise-cost hypothesis.
- **P3 (ignored hint): not triggered** — 75% ≥ 50% mention rate; no
  steering re-run needed. Consumption is not the bottleneck.
- **P4 (grep-equivalence, arm A ≥ 85% on C): raw 83.3% (nominally not met),
  100% conditional on working tools.** The spirit of P4 is clearly
  supported: the corpus fact is derivable by search within 6 calls.
- **P5 (decoys: B < A): not triggered** (B 6/8 vs A 5/8) — but the
  false-authority pattern was observed once (D1-b-r2), and the BASELINE
  commits the same error class without any tail (D1-a twice, C4-a-r1).

## Decision (per the preregistered rule)

"P4, or P2 breached, or P1 null → gate the tail back / opt-in." P2 is
breached and P1 is not credibly met → **the preregistered decision is:
do not extend connectivity reach further onto the workhorses; the tail's
find-value is search-equivalent for an agent with 6 calls, and it carries
a measurable exploration/noise cost on neutral tasks. Tier-1 + deliberate
audit surfaces (find_divergence, preview) is the honest scope.**
Uncertainty stated plainly: n = 2 reps; the token breach and the P1 margin
are both within reach of a larger-n reversal. What would overturn this:
a v2 with ≥ 4 reps showing the N-class token gap < 10% AND a class-C
setting where search is genuinely insufficient (e.g., cross-language
reference chains, larger corpora, tighter call budgets).

## Product findings (independent of the decision)

1. **Recall ceiling, underscore names** (curation finding, PROTOCOL.md):
   `is_offgraph_reachable` skips ALL leading-underscore Python names —
   private helpers, the most common real dead-code class, can never fire.
2. **Recall ceiling, attribute-name collisions**: `.parts` attribute
   mentions protect the unrelated function `parts()` — the bare-name
   counter cannot distinguish attribute access from function reference.
3. **Natural FP families confirmed at scale**: stdlib duck-typing
   (MockRequest), framework overrides (FlaskGroup/click), template-ref
   resolver misses (tutorial routes). All fire today; the "candidates, not
   verdicts" + dynamic-dispatch down-weight wording did NOT stop a
   haiku-grade consumer from recommending removal once (D1-b-r2).
4. **The calibration problem predates the tail**: the baseline arm asserted
   verified-alive functions as removable without any connectivity signal.
   Dead-code tasks tempt agents into "no grep hits = removable" regardless;
   a hint that arrives WITH a verification affordance ("check dynamic
   dispatch / stdlib protocols / templates before concluding") might improve
   on both arms — untested, goes to the backlog, measure first.
5. Consumption works: the tail, once present, is read and cited (75%).
